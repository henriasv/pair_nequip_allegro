User guide

Running NequIP on many GPUs

How to compile and run a multi-rank NequIP model with pair_style nequip in LAMMPS. This mirrors the docs page shipped on the fork (docs/integrations/lammps/multirank.md).

1Compile the model

nequip-compile \
  path/to/model.nequip.zip  path/to/model.nequip.pt2 \
  --device cuda \
  --mode aotinductor \
  --target pair_nequip_multirank \
  --modifiers enable_OpenEquivariance   # optional acceleration
  • Only --mode aotinductor is supported for this target.
  • The target auto-applies the enable_PairNequIPGhostExchange modifier — never pass it yourself (with any other target it is an error).
  • For pair_* targets the custom-op libraries an acceleration needs (e.g. OpenEquivariance's) are embedded into the .pt2, so the artifact is self-contained for LAMMPS.
  • Compiling an older packaged model triggers an automatic re-bundle that grafts multi-rank support onto the package's own bundled source; predictions are verified unchanged. Models re-exported from a checkpoint with a current nequip never need this.

2Run in LAMMPS

newton          on
pair_style      nequip
pair_coeff      * * model.nequip.pt2 <type name 1> <type name 2> ...
  • newton pair on is required — ghost forces return to their owners through LAMMPS' standard reverse communication, as for pair_allegro.
  • Run one MPI rank per GPU. With Kokkos (-sf kk, style resolves to nequip/kk) the feature exchange stays on the GPU and uses GPU-aware MPI:
srun --ntasks-per-node=8 --gpus-per-node=8 lmp \
  -k on g 8 -sf kk -pk kokkos newton on neigh half gpu/aware on -in in.script
  • Bind CPUs to their GPUs' NUMA domains — unbound ranks cost far more than a few percent in multi-node runs (see the evaluation page's methodology note).
  • The pair style detects multi-rank capability from the model; a single-rank model on several ranks aborts with an error that includes the exact recompile command.

3Verify a deployment

Compile both pair_nequip and pair_nequip_multirank targets from the same model, run both on one rank on a small periodic cell (PBC ⇒ ghosts exist, so the exchange path actually executes), and compare potential energies (tolerance 1e-4 eV/atom). Multi-rank potential energy must also be invariant to the number of ranks. Never skip this for fine-tuned or older packaged models — a wrong bundle fails silently, which is exactly what this gate catches.
